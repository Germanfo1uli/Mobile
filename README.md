# Жуки — лабораторные работы по ПМУ

Android-приложение на Kotlin и Jetpack Compose, которое развивается по этапам практических работ: от первого экрана и регистрации игрока до вкладок, игрового процесса, базы результатов и сетевых данных.

## Что реализовано

- стартовые экраны приложения;
- регистрационная форма игрока: ФИО, пол, курс, сложность и дата рождения;
- вычисление и отображение знака зодиака;
- вкладки «Досье», «Правила», «Авторы» и «Настройки»;
- правила игры из HTML-ресурса;
- настройки скорости, количества насекомых, интервала бонусов и длительности раунда;
- модульный тест расчёта знака зодиака и интерфейсные тесты Compose.

## Требования

- Windows 10/11 x64;
- Android Studio Quail или новее;
- JDK 21 (встроенный JBR Android Studio подходит; минимум для AGP 9.1 — JDK 17);
- Android SDK 36.1;
- интернет при первой синхронизации Gradle.

Проект использует Android Gradle Plugin 9.1.0 и Gradle 9.3.1.
Проверка пути Android Gradle Plugin отключена, потому что учебная папка Windows содержит кириллицу.

## Запуск в Android Studio

1. Откройте Android Studio.
2. Выберите **Open** и укажите папку `labMob` внутри репозитория.
3. Дождитесь окончания **Gradle Sync** и установки предложенных компонентов SDK.
4. Создайте виртуальное устройство в **Device Manager** либо подключите Android-телефон с включённой USB-отладкой.
5. Выберите конфигурацию `app` и нажмите **Run**.

## Проверка из командной строки

Из папки `labMob`:

```powershell
.\gradlew.bat test
.\gradlew.bat assembleDebug
```

Отладочный APK создаётся в `labMob/app/build/outputs/apk/debug/app-debug.apk`.

## Структура этапов

- лабораторная 1 — базовое Android-приложение;
- лабораторная 2 — регистрация игрока и знак зодиака;
- лабораторная 3 — вкладки, правила, авторы и настройки;
- последующие работы — игровой экран, Room, датчики, Retrofit, ViewModel и Koin.

История Git сохраняет авторство уже выполненных изменений. Новые коммиты добавляются по мере реальной разработки и проверки проекта.
